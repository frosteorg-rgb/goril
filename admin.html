Player lost their account after an update?

Find the player's NEW profile in Players (sort by Newest) and open it, then use Link old profile to pull their old coins, cosmetics and role across. Players can also do this themselves from the in-game menu with their old ID.

Test mod menu (anti-cheat test tool)

An external cheat menu that runs outside the game, like one a player would sneak in. It hooks the browser's WebSocket and edits the packets the game sends. Nothing in index.html or server.js is changed. Give the script only to your own test account.
How to use: open the game on the test account, press F12, open Console, paste the script, press Enter. The menu appears on the right (Insert key hides it). Or install the .user.js with Tampermonkey (it runs at document-start so it hooks before the game connects). Pasting it again toggles the menu.
